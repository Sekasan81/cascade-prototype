# Характеристики пассажиров

СТАТУС: рабочая дизайн-документация будущей версии. Не внедрено в игру.

Этот файл предназначен для характеристик конкретного пассажира, которые могут отличаться даже внутри одной расы.

## Вместимость в варпе

Текущие значения по расам:

| Раса | Вместимость |
|---|---:|
| 🧑 Гуманоиды | 1 |
| 🐜 Инсектоиды | 1 |
| 🍄 Микоиды | 1 |
| 👽 Ксеноморфы | 1–2 |
| 💧 Акватики | 1 |
| 🐸 Амфибии | 1 |
| 🤖 Синтетики | 1–3 |
| 🪨 Литоиды | 2 |

Для ксеноморфов и синтетиков вместимость является следствием характеристики «Размер» ниже.

## Размер

Предварительная система:

| Размер | Вместимость в варпе | Доступен |
|---|---:|---|
| Маленький | 1 место | Ксеноморфы, Синтетики |
| Средний | 2 места | Ксеноморфы, Синтетики |
| Большой | 3 места | Только Синтетики |

Правило:
- размер является характеристикой конкретного пассажира;
- у ксеноморфов возможны маленький и средний размеры;
- у синтетиков возможны маленький, средний и большой размеры;
- большой размер доступен только синтетикам.

Система размера пока не детализирована и не внедрена. Дополнительные эффекты размера будут определены позже.


## Состоятельность

Состоятельность — характеристика конкретного пассажира. Она будет использоваться для формирования его экономического профиля и в будущем может влиять на награду за перевозку и другие параметры.

Текущие уровни:

- 💸 Бедный
- 🪙 Средний класс
- 💰 Богатый
- 👑 Миллионер
- 💎 Магнат

Числовые коэффициенты, влияние на награду, вероятность появления и другие эффекты пока не определены.


## Идея: связь состоятельности и качества комнаты

Отдельная черновая механика для дальнейшего обсуждения:

- состоятельность пассажира определяет минимальное качество комнаты, которое он готов принять;
- 💸 Бедный — может принять комнату любого качества, включая 0 звёзд;
- 🪙 Средний класс — требует минимум 1 звезду;
- 💰 Богатый — требует минимум 2 звезды;
- 👑 Миллионер — требует минимум 3 звезды;
- 💎 Магнат — требует минимум 4 звезды;
- если подходящей комнаты нет, пассажира нельзя заселить в неподходящую комнату без отдельной механики/штрафа, которую определим позже.

Точные значения количества звёзд и последствия отсутствия подходящей комнаты пока являются черновыми и требуют балансировки.


## Идея: расширенная вместимость варпа

Отдельная идея для дальнейшего обсуждения, не являющаяся текущим зафиксированным правилом:

- увеличить вместимость одного варпа примерно до 10 слотов вместо текущей небольшой вместимости;
- сделать шкалу размера пассажира более детальной;
- возможная шкала: Крошечный = 1 слот, Маленький = 2, Средний = 3, Большой = 4, Огромный = 5, Гигантский = 6;
- конкретные диапазоны размеров для рас определить позже;
- цель идеи — увеличить вариативность загрузки варпа и сделать размер более значимым игровым параметром.

Пока не использовать эту шкалу как утверждённую механику.


## Идея: связь размера, потребления и доходности

Отдельная идея для дальнейшего обсуждения, не являющаяся пока утверждённой формулой:

- размер пассажира может влиять на скорость потребления требуемого ресурса;
- чем больше пассажир, тем выше его потребление за единицу времени;
- размер может одновременно влиять на экономическую ценность пассажира;
- итоговая награда может рассчитываться из сочетания **размера + состоятельности**;
- состоятельность определяет базовую ценность пассажира, а размер масштабирует её;
- маленький + бедный пассажир должен приносить мало денег, но создавать небольшую нагрузку на станцию;
- гигант + бедный пассажир должен приносить заметно больше денег, но потреблять значительно больше ресурсов и занимать больше мест в варпе;
- гигант + магнат должен быть очень ценным пассажиром, но одновременно создавать большую нагрузку на станцию;
- конкретные коэффициенты размера, скорости потребления, награды и другие экономические формулы определить позже.

Цель идеи — сделать комбинацию характеристик пассажира важнее отдельных параметров и создать выбор между доходностью и нагрузкой на станцию.
