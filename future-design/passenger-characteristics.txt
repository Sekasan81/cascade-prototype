# Характеристики пассажиров

СТАТУС: рабочая дизайн-документация будущей версии. Не внедрено в игру.

Этот файл предназначен для характеристик конкретного пассажира, которые могут отличаться даже внутри одной расы.

## Вместимость в варпе

Текущие значения по расам:

| Раса | Вместимость |
|---|---:|
| 🧑 Гуманоиды | 1 |
| 🐜 Инсектоиды | 1 |
| 🍄 Микоиды | 1 |
| 👽 Ксеноморфы | 1–2 |
| 💧 Акватики | 1 |
| 🐸 Амфибии | 1 |
| 🤖 Синтетики | 1–3 |
| 🪨 Литоиды | 2 |

Для ксеноморфов и синтетиков вместимость является следствием характеристики «Размер» ниже.

## Размер

Предварительная система:

| Размер | Вместимость в варпе | Доступен |
|---|---:|---|
| Маленький | 1 место | Ксеноморфы, Синтетики |
| Средний | 2 места | Ксеноморфы, Синтетики |
| Большой | 3 места | Только Синтетики |

Правило:
- размер является характеристикой конкретного пассажира;
- у ксеноморфов возможны маленький и средний размеры;
- у синтетиков возможны маленький, средний и большой размеры;
- большой размер доступен только синтетикам.

Система размера пока не детализирована и не внедрена. Дополнительные эффекты размера будут определены позже.


## Состоятельность

Состоятельность — характеристика конкретного пассажира. Она будет использоваться для формирования его экономического профиля и в будущем может влиять на награду за перевозку и другие параметры.

Текущие уровни:

- 💸 Бедный
- 🪙 Средний класс
- 💰 Богатый
- 👑 Миллионер
- 💎 Магнат

Числовые коэффициенты, влияние на награду, вероятность появления и другие эффекты пока не определены.


## Идея: расширенная вместимость варпа

Отдельная идея для дальнейшего обсуждения, не являющаяся текущим зафиксированным правилом:

- увеличить вместимость одного варпа примерно до 10 слотов вместо текущей небольшой вместимости;
- сделать шкалу размера пассажира более детальной;
- возможная шкала: Крошечный = 1 слот, Маленький = 2, Средний = 3, Большой = 4, Огромный = 5, Гигантский = 6;
- конкретные диапазоны размеров для рас определить позже;
- цель идеи — увеличить вариативность загрузки варпа и сделать размер более значимым игровым параметром.

Пока не использовать эту шкалу как утверждённую механику.
