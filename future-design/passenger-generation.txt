# Генерация пассажиров — согласованная концепция

Документ описывает правила генерации пассажиров. Это только документация и не используется игрой.

## 1. Генерация зависит от развития варпов

При создании нового пассажира игра должна учитывать максимальную доступную вместимость варпа на станции.

- При начальной вместимости 4 места обычные пассажиры, которым требуется больше 4 мест, не генерируются.
- После улучшения хотя бы одного обычного варпа до 6 мест становятся доступны обычные пассажиры-гиганты, которым требуется 6 мест.
- Аналогично открываются обычные пассажиры с большими требованиями по мере развития варпов.
- Генератор не должен создавать пассажира, которого невозможно отправить при текущем развитии станции.

Для определения доступности используется максимальная вместимость хотя бы одного доступного варпа, а не сумма мест всех варпов.

Пример:
- Варп №1 — 4 места
- Варп №2 — 4 места
- Варп №3 — 6 мест (улучшен)

В этом случае обычный пассажир на 6 мест может появиться, а пассажир на 7 мест — нет.

## 2. Генерация зависит от открытых точек назначения

Точки назначения определяют, какие пассажиры могут появляться на станции.

Если необходимая пассажиру точка назначения ещё не открыта, такой пассажир вообще не должен генерироваться.

Примеры:
- Торговый узел не открыт → пассажиры-торговцы, которым требуется Торговый узел, не приходят.
- Торговый узел открыт → торговцы становятся доступными для генерации.
- Водная планета не открыта → акватики, которым требуется эта точка назначения, не приходят.
- После открытия водной планеты соответствующие акватики становятся доступными для генерации.

Таким образом, открытие новой точки назначения может добавлять в пул новые расы, профессии и другие типы пассажиров.

Важно: точка назначения определяет доступность пассажира для генерации, а варп определяет возможность его отправки. Это разные механики.

## 3. Исключение для квестовых пассажиров

После принятия контракта на отправку пассажиров для него создаётся специальный варп, рассчитанный на всю требуемую группу; квестовые пассажиры генерируются только для этого контракта и принимаются только его варпом. Это исключение не открывает соответствующие размеры для обычной генерации.

Генератор ориентируется на оставшееся количество пассажиров по контракту. Засчитывается только успешно завершённая отправка. Если квестовый пассажир улетел, не будучи отправленным, он не увеличивает прогресс и заменяется пассажиром для того же незакрытого требования. Генератор не создаёт пассажиров сверх оставшегося количества.

## 4. Общий принцип

Генератор обычных пассажиров должен учитывать одновременно:
1. открытые точки назначения;
2. максимальную вместимость доступного обычного варпа;
3. другие открытые технологии и условия прогрессии.

Отдельный генератор квестовых пассажиров учитывает требования и оставшийся прогресс активного контракта.

Обычный пассажир генерируется только в том случае, если он соответствует доступному пулу станции и может быть отправлен с учётом текущего развития обычных варпов. Квестовые пассажиры подчиняются отдельному правилу выше.

## 5. Пока не определено

Следующие вопросы оставить для дальнейшего обсуждения:
- конкретный список точек назначения;
- точная привязка рас, профессий и особенностей пассажиров к направлениям;
- как распределяются вероятности между доступными пассажирами;
- точные правила расчёта требуемых мест;
- специальные/сюжетные пассажиры;
- дополнительные условия генерации.
