# Система варпов — черновик для будущего обсуждения

Документ описывает согласованную механику варпов. Это только документация и не используется игрой.

## 1. Общая идея

Варпы заменяют старую систему фиксированных рейсов.

В тестовой версии станции есть 3 стандартных варпа. Игрок в дальнейшем может покупать новые варпы и увеличивать вместимость существующих.

Варп имеет пропускную способность в пассажирских местах.

Комната и варп используют разные ограничения:
- комната принимает одного пассажира независимо от того, сколько мест он занимает в варпе;
- варп ограничен количеством пассажирских мест.

## 2. Направление варпа

Один варп в один момент времени работает только с одним направлением.

Первый назначенный на варп пассажир определяет направление, например:
- Марс;
- Sigma-4;
- другое открытое направление.

Пассажиров с другим направлением в этот же варп добавить нельзя.

После завершения перехода варп освобождается и может быть использован для другого направления.

## 3. Назначение пассажира на варп

Игрок открывает карточку пассажира и назначает:
- комнату;
- пункт назначения;
- варп.

После подтверждения карточка закрывается, пассажир перемещается в комнату.

При этом варп **не запускается автоматически**.

Пассажир ждёт в комнате:
- комната занята;
- пассажир потребляет ресурсы;
- пассажир остаётся связан с выбранным варпом;
- игрок может продолжать заполнять этот варп подходящими пассажирами.

## 4. Запуск варпа

Справа на экране отображается соответствующий варп и кнопка запуска.

Например:

Варп №1 → Марс
Занято: 5 / 6 мест
[ЗАПУСТИТЬ ВАРП]

При нажатии «Запустить варп»:
1. проверяется наличие необходимых варп-ячеек;
2. варп-ячейки списываются;
3. начинается подготовка варпа;
4. запускается таймер подготовки.

До запуска таймер подготовки не идёт.

## 5. Варп-ячеейки

Подготовка варпа не бесплатна.

Для запуска требуются специальные варп-ячейки, которые в дальнейшем производятся на фабрике.

Количество требуемых ячеек связано с прокачкой варпа. Точные значения пока не определены.

Связь должна обеспечивать прогрессию:
- более мощный варп имеет большую пропускную способность;
- более мощный варп требует больше варп-ячеек для запуска;
- развитие фабрики обеспечивает производство необходимых ячеек.

## 6. Заполнение варпа

Пока варп не запущен, игрок может добавлять в него подходящих пассажиров того же направления, если хватает свободных мест.

После запуска состав варпа фиксируется.

Все пассажиры, включённые в один запущенный варп, улетают одновременно после окончания подготовки.

## 7. Неполностью заполненный варп

Игрок сам решает, когда запускать варп.

Можно запустить его неполностью заполненным, например:
- вместимость 10;
- занято 4;
- игрок запускает варп.

Это не отдельная ошибка или штраф системы. Игрок самостоятельно принимает экономическое решение.

Дилемма:
- ждать заполнения варпа — эффективнее расходовать варп-ячейки, но пассажиры дольше занимают комнаты и потребляют ресурсы;
- запускать раньше — быстрее освобождать комнаты, но расходовать варп-ячейки на неполностью загруженный варп.

## 8. Завершение

После окончания таймера подготовки:
- все пассажиры варпа одновременно улетают;
- комнаты освобождаются;
- места варпа освобождаются;
- начисляется соответствующая награда;
- варп становится доступен для нового направления.

## 9. Пока не определено

Оставить для дальнейшего обсуждения:
- точные значения вместимости варпов;
- стоимость новых варпов;
- стоимость расширения вместимости;
- формулу количества варп-ячеек;
- время подготовки варпов;
- можно ли каким-либо образом ускорять подготовку;
- максимальную вместимость варпа;
- точные правила отображения нескольких пассажиров внутри одного варпа.
