# ВАРИАТИВНОСТЬ ТЕКСТА КВЕСТОВ

## Назначение

Этот файл хранит не правила генерации квестов и не баланс наград, а набор текстовых составляющих, из которых генератор собирает читаемое описание квеста.

Цель: квест должен выглядеть как небольшая ситуация или просьба, а не как сухой список условий.

В этом файле постепенно создаются контекстные заготовки для всех точек портала. Для каждой планеты/точки задаются несколько основных причин появления квеста, а для каждой причины — несколько сюжетных ситуаций и наиболее подходящие профессии.

Сейчас используются 5 точек портала:
- Луна
- Марс
- Венера
- Европа
- Титан

Принцип работы:
- не делать огромную библиотеку уникальных готовых квестов;
- для каждой точки выбрать несколько характерных причин;
- на каждую причину сделать по 3 сюжетных варианта;
- использовать ограниченный набор профессий, которые естественно подходят к данной причине и месту;
- затем генератор подставляет реальные параметры квеста: количество пассажиров, расу, профессию, награду, условия и другие данные;
- после проверки подхода таким же образом заполнить остальные точки.

Пример общей структуры:

[Вступление] + [Причина] + [Что требуется] + [Кого/что требуется] + [Дополнительное условие] + [Награда/завершение]

Пример:
«На Марсе открывается новая шахта. Для запуска работ срочно нужны инженеры. Доставьте 2 инженеров на Марс. За успешную перевозку станция получит 800 кредитов.»

# 1. ВСТУПЛЕНИЕ / СИТУАЦИЯ

Короткие фразы, которые вводят игрока в ситуацию.

Примеры:

- На Марсе начинается новый строительный проект.
- На станции возникла нехватка специалистов.
- На одной из колоний готовятся к важному запуску.
- Поступил срочный запрос от местной администрации.
- Колония расширяется, и ей нужны новые работники.
- На планете открывается новый объект.
- Местные власти ищут помощь с перевозкой.
- На орбитальной станции готовятся к прибытию нового персонала.
- Пришёл запрос на срочную транспортировку.
- Один из наших постоянных клиентов прислал новый заказ.

---

# 2. ПРИЧИНА / ЗАЧЕМ НУЖНЫ ПАССАЖИРЫ

Объясняет, почему появился заказ.

Примеры:

- Для запуска работ не хватает специалистов.
- Для нового объекта нужны дополнительные рабочие.
- Из-за расширения колонии требуется больше персонала.
- Старый экипаж не справляется с объёмом работы.
- Новый проект требует специалистов определённого профиля.
- На месте неожиданно возникла нехватка рабочей силы.
- Для завершения строительства необходимо усилить команду.
- Администрация пытается быстро закрыть несколько вакансий.
- Заказчик готов хорошо заплатить за срочную доставку.
- Работы уже начались, поэтому медлить нельзя.

---

# 3. ФОРМУЛИРОВКИ «ТРЕБУЕТСЯ»

Основной блок требования.

Обычные:

- Требуются {пассажиры}.
- Нужны {пассажиры}.
- Необходимо доставить {пассажиров}.
- Нужно найти и доставить {пассажиров}.
- Для работы требуются {пассажиры}.
- Заказчик ожидает {пассажиров}.
- На месте ждут {пассажиров}.
- Колонии необходимы {пассажиры}.
- Для выполнения работ нужны {пассажиры}.

Более живые:

- Без {пассажиров} проект не сможет нормально стартовать.
- Есть только одна проблема — на месте не хватает {пассажиров}.
- Сейчас заказчику особенно нужны {пассажиры}.
- Самая большая проблема — найти подходящих {пассажиров}.
- В первую очередь нужно доставить {пассажиров}.

---

# 4. РАСА / ТИП ПАССАЖИРА

Переменная часть, подставляемая генератором.

Шаблон:

- {количество} {раса}
- {количество} представителей расы {раса}
- несколько {раса}
- группа {раса}
- небольшая группа {раса}
- специалисты из числа {раса}

Примеры:

- 2 инженеров-людей
- 3 микоидов
- группа синтетиков
- 2 представителя водной расы

Важно: конкретные названия рас, профессий и их формы должны браться из соответствующих таблиц/справочников, а не вручную дублироваться здесь.

---

# 5. ПРОФЕССИЯ

Фразы, связывающие пассажира с профессией.

Примеры:

- инженеры
- исследователи
- торговцы
- дипломаты
- туристы
- беженцы

Формулировки:

- требуются {профессия}
- нужны специалисты: {профессия}
- нужны опытные {профессия}
- заказчик ищет {профессия}
- на месте ждут {профессия}
- особенно нужны {профессия}

---

# 6. ДОПОЛНИТЕЛЬНОЕ УСЛОВИЕ

Используется, когда квест содержит второй тип требования или дополнительный фильтр.

Примеры:

- Также требуется доставить {второе требование}.
- Кроме того, нужны {второе требование}.
- Помимо основных специалистов, заказчик ожидает {второе требование}.
- Одними специалистами дело не обойдётся — нужны ещё {второе требование}.
- Дополнительно необходимо доставить {второе требование}.
- Заодно требуется отправить {второе требование}.

Пример:
«Для запуска шахты нужны инженеры. Кроме того, администрация ищет исследователей для контроля нового оборудования.»

---

# 7. СРОЧНОСТЬ

Фразы, которые делают квест более живым.

Низкая/обычная срочность:

- Особой спешки нет, но заказ желательно выполнить в ближайшее время.
- Заказчик рассчитывает получить их в ближайшее время.
- Сроки позволяют немного подождать.

Средняя:

- С этим лучше не затягивать.
- Заказ желательно выполнить как можно скорее.
- Времени не так много.
- Работы уже начинаются, поэтому лучше поторопиться.

Высокая:

- Ситуация срочная.
- Ждать долго заказчик не может.
- Работы уже начались, и специалисты нужны немедленно.
- Каждый час задержки создаёт проблемы.
- Заказчик просит выполнить доставку как можно быстрее.

---

# 8. ОПИСАНИЕ НАГРАДЫ

Не обязательно каждый раз писать просто «Награда: 500 кредитов».

Варианты:

- За доставку станция получит {награда} кредитов.
- Заказчик готов заплатить {награда} кредитов.
- За успешное выполнение обещана награда в {награда} кредитов.
- Оплата за работу составит {награда} кредитов.
- Заказ выглядит выгодным — заказчик предлагает {награда} кредитов.
- За выполнение заказа будет выплачено {награда} кредитов.
- Заказчик не скупится и предлагает {награда} кредитов.

Для особо высокой награды:

- Заказчик готов заплатить необычно крупную сумму — {награда} кредитов.
- Похоже, заказ действительно важный: за него предлагают {награда} кредитов.

---

# 9. ЗАВЕРШЕНИЕ

Финальная фраза перед механическим блоком квеста или вместо него.

Примеры:

- Доставьте их на {планета}, чтобы заказ считался выполненным.
- Главное — доставить пассажиров в пункт назначения.
- После успешной доставки заказ будет закрыт.
- Как только нужные пассажиры прибудут на место, работа считается выполненной.
- Заказ будет выполнен после отправки требуемой группы.

# 10. ПРИМЕРЫ ГОТОВЫХ СБОРOК

### Пример 1 — простой

«На Марсе открывается новая шахта. Для запуска работ нужны инженеры. Доставьте 2 инженеров на Марс. За успешную доставку станция получит 800 кредитов.»

### Пример 2 — с двумя типами пассажиров

«Колония расширяется, и местным не хватает специалистов. В первую очередь нужны 2 инженера. Кроме того, администрация ищет 1 исследователя для работы с новым оборудованием. За выполнение заказа обещана награда в 1200 кредитов.»

### Пример 3 — срочный

«На одной из колоний возникла авария. Для восстановления оборудования срочно нужны инженеры. Времени мало — заказчик просит доставить 3 специалистов как можно скорее. За успешную доставку будет выплачено 1500 кредитов.»

### Пример 4 — высокая награда

«На Марсе готовится запуск нового промышленного комплекса. Проект требует редких специалистов, и найти их оказалось непросто. Нужны 2 опытных инженера. Заказчик готов заплатить необычно крупную сумму — 10 000 кредитов.»

# 11. ПРИМЕР КОНТЕКСТА: ЛУНА

Для Луны сейчас используем 3 основные причины:
1. Колония
2. Добыча
3. Строительство

На каждую причину предусмотрено по 3 сюжетных варианта.

Для Луны в качестве наиболее подходящих профессий пока используются:
- Инженер — оборудование, технические работы, строительство и запуск объектов.
- Исследователь — изучение месторождений, поверхности и необычных объектов.
- Инспектор — проверка готовых объектов, шахт и состояния колонии.

## Луна — Колония

### 1. Расширение колонии — Инженеры

«Лунная колония продолжает расширяться. Новые жилые модули уже готовы, но для их обслуживания не хватает специалистов. Колонии требуются инженеры.»

### 2. Необычная находка — Исследователи

«Учёные колонии обнаружили необычные особенности в окружающей местности. Для дальнейшего изучения администрация запрашивает исследователей.»

### 3. Проверка колонии — Инспекторы

«После нескольких технических сбоев администрация решила провести полную проверку колонии. На Луну требуется доставить инспекторов.»

## Луна — Добыча

### 4. Запуск новой шахты — Инженеры

«На Луне готовится запуск новой шахты. Оборудование уже доставлено, но для его настройки нужны специалисты. Требуются инженеры.»

### 5. Исследование месторождения — Исследователи

«Геологи обнаружили перспективный участок, однако его ещё необходимо изучить. Для оценки нового месторождения требуются исследователи.»

### 6. Проверка шахты — Инспекторы

«Одна из лунных шахт готовится увеличить объёмы добычи. Перед запуском нового оборудования администрация хочет провести проверку. Нужны инспекторы.»

## Луна — Строительство

### 7. Новый комплекс — Инженеры

«На Луне начинается строительство нового комплекса. Для установки и настройки оборудования требуются инженеры.»

### 8. Необычная структура — Исследователи

«Во время подготовки строительной площадки обнаружили необычную структуру под поверхностью. Строительство приостановлено до прибытия исследователей.»

### 9. Финальная проверка — Инспекторы

«Новый строительный комплекс почти готов к эксплуатации. Перед открытием необходимо провести финальную проверку. Администрация ожидает инспекторов.»

Примечание: это не список из 9 неизменяемых квестов. Это набор сюжетных заготовок для генератора. Реальные количество пассажиров, раса, размер, дополнительные условия, награда и другие параметры подставляются из механики генерации квестов.

# 12. ПРИМЕР КОНТЕКСТА: МАРС

Для Марса сейчас используем 3 основные причины:
1. Терраформирование
2. Добыча
3. Промышленность

На каждую причину предусмотрено по 3 сюжетных варианта.

Для Марса в качестве наиболее подходящих профессий используются:
- Инженер — технические системы, оборудование, инфраструктура и промышленные объекты.
- Исследователь — поверхность, атмосфера, месторождения и результаты терраформирования.
- Торговец — поставки оборудования, материалов и организация промышленной торговли.
- Дипломат — переговоры между марсианскими поселениями и урегулирование спорных вопросов.

## Марс — Терраформирование

### 1. Подготовка нового участка — Инженеры

«Работы по освоению Марса продолжаются. На новом участке устанавливают оборудование для подготовки среды, но местной бригаде не хватает специалистов. Требуются инженеры.»

### 2. Исследование атмосферы — Исследователи

«Учёные обнаружили необычные изменения в атмосфере нового района. Необходимо провести дополнительные исследования и собрать данные. На Марс запрашивают исследователей.»

### 3. Переговоры между колониями — Дипломаты

«Между несколькими марсианскими поселениями возникли разногласия по поводу дальнейшего освоения территории. Для переговоров требуется независимая группа представителей. На Марс нужны дипломаты.»

## Марс — Добыча

### 4. Новая шахта — Инженеры

«На Марсе обнаружено новое месторождение. Подготовка шахты уже началась, но для запуска добывающего оборудования не хватает специалистов. Требуются инженеры.»

### 5. Исследование месторождения — Исследователи

«Разведка обнаружила участок с необычным составом пород. Прежде чем начинать добычу, необходимо изучить месторождение. На Марс запрашивают исследователей.»

### 6. Первые поставки — Торговцы

«Новая шахта готовится к запуску, и местная администрация ищет поставщиков для первых партий оборудования и материалов. На Марс требуется доставить торговцев.»

## Марс — Промышленность

### 7. Запуск промышленного комплекса — Инженеры

«На Марсе готовится запуск нового промышленного комплекса. Оборудование уже доставлено, но для его установки и настройки нужны специалисты. Требуются инженеры.»

### 8. Цепочка поставок — Торговцы

«Новый завод начинает работу и срочно формирует цепочку поставок. Местным предприятиям нужны специалисты, способные заключить первые контракты. На Марс запрашивают торговцев.»

### 9. Испытание новой технологии — Исследователи

«На промышленном объекте начали испытания новой технологии, рассчитанной на марсианские условия. Для анализа первых результатов требуются исследователи.»

Примечание: это не список из 9 неизменяемых квестов. Это набор сюжетных заготовок для генератора. Реальные количество пассажиров, раса, размер, дополнительные условия, награда и другие параметры подставляются из механики генерации квестов.

# 13. ПРАВИЛА ДЛЯ ГЕНЕРАТОРА

1. Не собирать каждый квест по одной и той же фиксированной фразе.
2. Выбирать случайные совместимые варианты из блоков.
3. Не использовать все блоки одновременно — часть блоков должна быть необязательной.
4. Текст должен соответствовать реальным условиям сгенерированного квеста.
5. Не добавлять в текст детали, которых нет в механике квеста.
6. Не повторять одну и ту же формулировку слишком часто.
7. Для простых квестов использовать короткий текст.
8. Для сложных квестов добавлять причину, контекст и дополнительные требования.
9. Срочность, размер награды и другие детали должны отражать реальные параметры квеста, если такие связи будут утверждены.
10. Для каждой точки портала сначала определять характерные причины и подходящие профессии, а уже затем создавать текстовые варианты.
11. Не требуется создавать отдельный готовый текст для каждой профессии. Профессии выбираются по смысловой близости к ситуации.
12. После заполнения одной точки портала использовать тот же принцип для следующих точек: 3 причины × 3 сюжетных варианта, с подходящими для данной точки профессиями.
13. Этот файл содержит именно текстовые шаблоны, сюжетные заготовки и варианты формулировок. Правила расчёта условий, пассажиров и наград хранятся в соответствующих файлах дизайна.
