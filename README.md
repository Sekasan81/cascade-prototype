# Тихая орбита — прототип пересадочной станции, версия 02

Актуальные правила обновления: [CHANGELOG.md](CHANGELOG.md). Новые иллюстрации: [ART-PROMPTS.md](ART-PROMPTS.md).

Полностью самостоятельная реализация по текстам `future-design`, октябрь 2026. Старый игровой код не использован. Игра: https://sekasan81.github.io/cascade-prototype/

## Запуск

Node.js 22+: `node serve.mjs`, затем http://127.0.0.1:4173 . Сборка не требуется. `node tests/engine.test.mjs` запускает проверки механик. Браузерные сценарии требуют Playwright и установленного браузера; `node tests/browser.mjs` (локально Edge, для Chromium задайте `BROWSER_CHANNEL=chromium`).

## Как играть

1. Игра открывается на паузе. Принимайте инженеров с запасом 3 единицы.
2. В комнате выберите портал на Луну и запустите его. Продолжите время; можно выбрать 2×.
3. Отправьте партии 1 + 2 + 2, затем откройте фабрику за 750 кредитов.
4. Принимайте контракты, отправляйте подходящих гостей через отдельные порталы. После доставки вручную завершайте контракт.
5. Репутацией исследуйте новые возможности; кредитами оплачивайте инфраструктуру и ресурсы.

Пробел переключает паузу вне полей ввода. Фабрика при входе ставит время на паузу. Отключение вкладки также автоматически ставит игру на паузу (удобство прототипа). Сохранение в localStorage, без офлайн-прогресса. Раздел «Испытания» позволяет начать после обучения, открыть лабораторную конфигурацию и экспортировать отчёт или сохранение. Импорт пока отсутствует.

## Проверяемые системы

- Непрерывное время 1×/2× и единая пауза; плавные таймеры.
- 8 рас, 20 архетипов, 6 размеров и классов; таблицы вероятностей, циклов и выплат.
- Очередь без ухода по таймеру; отдельный 30-секундный интервал для каждого освободившегося места.
- Две универсальные комнаты, исследуемая третья, качество 0–5, запас среды, Min/Max, предупреждение частичного расхода, предел пребывания и скрытая страховка 2 с.
- Стандартные порталы 4→6→8→10, до пяти экземпляров, пять направлений; подготовка 10+4×мест секунд, расход ячеек только за занятые места.
- Контракты по расе и максимальному классу, отдельные порталы, уникальный зачёт, совместный спрос, гарантированный кандидат после двух промахов, ручная выдача наград, штраф отмены и обновление предложений.
- Фабрика 3×3 с расширяемыми ячейками до 5×5; отдельный пресет 4×4; три стадии производства, четыре ветки сырья, восемь чистых компонентов, усилители и энергия 50→70.
- Уровни переработчика/очистителя, сохранение уровня в инвентаре, блокировка снятия/смены рецепта в цикле, сохранение зарезервированных компонентов при остановке.
- Журнал, метрики, отдельные тестовые пресеты и локальное сохранение.
