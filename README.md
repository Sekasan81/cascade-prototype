# Пересадочная

Пошаговый 2D-прототип по плану межпланетной пересадочной станции от 20 сентября 2026 года.

Играть: https://sekasan81.github.io/cascade-prototype/

## Цель и управление

Отправьте минимум 16 из 22 пассажиров за шесть смен и не обанкротьтесь.

1. Выберите пассажира в очереди. Его карточка показывает среду, направления, срок и награду.
2. Подготовьте свободную комнату нужной среды. Терраны — сухая, аквари — водная, аэриды — газовая.
3. Примите пассажира, подтвердите направление и отправьте его. Это три отдельных действия.
4. Покупайте батареи и включайте производство по необходимости. Осмотр объектов бесплатный; действие занимает один такт.
5. Перед закрытием отправьте гостей и оставьте 12 кредитов на содержание. После 24 действий станция закрывается автоматически.

Повторный выбор действующего режима и недопустимые команды не расходуют такты. Состояние сохраняется в браузере после каждого действия. Старое сохранение предыдущего прототипа не используется.

## Что реализовано

- 6 смен, 22 фиксированных прибытия, две комнаты, три расы и три направления.
- 4 категории пассажиров, опыт станции и независимая репутация каждой расы.
- Энергия, запас батарей, генератор с топливом, вода и биоматериал.
- Терпение, усталость, сон, содержание, банкротство и итог партии.
- Три улучшения, сделка торговца, две истории с повторными встречами и подарками.
- Простая векторная 2D-графика; адаптивный интерфейс с выделением объекта и причинами блокировки действий.
- Предпросмотр изменения ресурсов и потерь до действия.
- Окно баланса: все основные числовые параметры применяются только к новой партии.
- Журнал и экспорт JSON с настройками, командами, ресурсами до/после и итогами смен.

Случайный режим и третья комната отложены, как предложено в плане. Короткие именные сцены работают внутри подтверждения маршрута, без дополнительных квестов.

## Проверка механик

Нужен Node.js с поддержкой ES-модулей и `structuredClone`.

```sh
node tests.mjs
```

25 проверок: первая смена точно по расчету PDF; запрет повторных наград; границы сроков и емкостей; производство и генератор; очередь; закрытие; банкротство; истории; сделки; сохранения и полный проход шести смен.

Тестовый оператор завершил партию с базовыми параметрами: **22/22 отправок, 0 потерь, 494 кредита**, генератор установлен, обе истории завершены с благодарностью. Это проверка выполнимости, а не пользовательский плейтест. Экономика намеренно соответствует исходным стартовым параметрам; высокий остаток денег — сигнал для будущих тестов сложности, а не доказательство финального баланса.

Чтобы сохранить машинный отчет, задайте переменную `STATION_REPORT_PATH` с путем к JSON до запуска тестов. Без нее тесты не записывают файлы.

## Локальный запуск

Статический проект без сборки, библиотек, внешних шрифтов и сетевых API. Откройте папку любым локальным HTTP-сервером, например:

```sh
python -m http.server 8000
```

Затем откройте http://localhost:8000. Двойной клик по `index.html` не подходит для ES-модулей.

## Файлы

- `engine.mjs` — чистая модель правил, конфигурация, сохранения.
- `app.mjs` — интерфейс и SVG-графика.
- `style.css` — адаптивное оформление.
- `tests.mjs` — проверки правил и тестовый оператор.
- `index.html` — страница запуска.

GitHub Pages публикует корень ветки `main`. Предыдущая версия остается доступной в истории Git.
