# Баланс 0.2 — очередь и индивидуальные потребности

## Поток и время

Базовые прибытия: такты 1, 5, 9, 13, 17. В начале дополнительно один гость. После каждого из первых 18 действий: 86% без добавочных гостей, 12% один, 2% двое. Бонус может совпасть с плановым прибытием. Ожидаемый поток: 8,88 гостя за смену, 53,28 за партию. Последние шесть рабочих действий отведены завершению обслуживания; сон гостей не создает, следующая смена открывается двумя.

Два помещения, но одна команда за такт. Минимальная цепочка обслуживания — 3 такта. Теоретический потолок 48 отправок за 144 действия; закупки, производство и перестройки уменьшают его. Цель 32 отправки дает запас на ошибки. Не требуется спасти всю очередь.

Очередь: 6 мест. Терпение беженца 16±2, туриста 14±2, дипломата и торговца 12±2 такта. Для каждого значение выпадает отдельно. На последнем такте можно принять гостя. После приема действует отдельный срок комнаты: 14/12/10/10. Уход из очереди −1 репутации, из комнаты −2; отказ при переполнении без штрафа. Открытые категории сохраняются после снижения репутации.

## Биоматериал и экономика

| Параметр | Значение |
|---|---:|
| Старт / емкость био | 120 / 240 |
| Беженец | 1–3 био |
| Турист | 3–6 био |
| Дипломат | 6–8 био |
| Торговец | 8–10 био |
| Аквари и аэриды | +1 био, максимум 10 |
| Нери / Ро | 7 / 5 био |
| Биосинтез | 9 био / 3 такта за 2 энергии |
| Срочная закупка | 40 био за 16 кредитов и 1 такт |
| Перестройка | 12 био, с улучшением 8 |
| Генератор / прочие улучшения | 40 / 30 био |
| Сделка торговца | 30 био за 10 кредитов |
| Подарок Нери при повторной встрече | 20 био |
| Стартовые кредиты / содержание смены | 80 / 30 |
| Награда по категориям | 10 / 14 / 18 / 22 кредита |

Расход пассажира виден заранее и списывается только при приеме. Био не расходуется каждый такт; помощь Нери отдельно стоит 2 био. Производство выключено в начале: нужно решить, когда потратить такт на включение. Закупка дает возможность восстановиться даже без энергии. Требуется место под всю партию. Производство продолжает работу во сне.

Дефицит времени — основное давление; экономика оставлена достаточно мягкой для исследования механик. Запаса 120 био не хватает на всю партию: автоматический диспетчер тратит только на гостей в среднем 294 био, дополнительно требуются перестройки. Награды уменьшены, содержание увеличено относительно 0.1, чтобы новый поток не давал прежний доход на каждого гостя.

## Результаты воспроизводимой проверки

Команда: `node balance-sim.mjs 200`. Начальные значения: `Math.imul(i+1,2654435761) >>> 0`, i=0…199. Диспетчер завершает размещенных гостей, выбирает совместимые комнаты, следит за снабжением и включает производство. Он не читает будущие случайные события. Код стратегии открыт рядом с игрой.

| Метрика | Минимум | Среднее | Максимум |
|---|---:|---:|---:|
| Прибыло | 43 | 53,0 | 63 |
| Отправлено | 36 | 39,7 | 42 |
| Ушло | 4 | 13,3 | 22 |
| Био на прием | 259 | 294,4 | 352 |
| Остаток кредитов | 266 | 403,0 | 532 |
| Максимальная очередь | 3 | 5,3 | 6 |
| Ушло из-за переполнения | 0 | 0,3 | 4 |

200/200 выполненных планов, 0 банкротств. Это проверка достижимости одной стратегией, а не оценка сложности для людей. Цель следующего ручного теста: заметны ли срочные гости, понятен ли момент включения производства, заставляет ли очередь выбирать без ощущения неизбежного проигрыша. Параметры потока, запасов, терпения и цели доступны в окне «Баланс».

24 проверки правил дополнительно охватывают двойной спавн, совпадение с расписанием, индивидуальные таймеры, переполнение, списание био, сохранение случайного потока после загрузки, отсутствие изменений от предпросмотра и повторных команд, сон, банкротство, подарки и прогрессию.
